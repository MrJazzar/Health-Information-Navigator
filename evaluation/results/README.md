# Evaluation result files

This directory receives timestamped evaluation and safety-run reports. Results are
generated by:

```powershell
python -m evaluation.run_evaluation
python -m evaluation.run_safety_tests
```

Use `python -m evaluation.run_evaluation --generate` only when API use is approved; it
sends fictional evaluation questions and retrieved text to Gemini. Do not edit raw
reports to conceal failures. Add human review fields in a copy or annotate the
timestamped output, preserving the original run. Do not add participant identities or
mental-health disclosures. No evaluation or participant results are pre-populated.
